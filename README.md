# Drift monitoring coursework

Completed coursework exploring data drift, model performance monitoring, and data quality tests with Evidently.

| Script | Exercise |
| --- | --- |
| `1_premiers_pas.py` | Compare subsets of the Adult dataset and export data drift reports. |
| `2_regression_monitoring.py` | Monitor regression performance using the diabetes dataset and simulated predictions. |
| `3_classification_monitoring.py` | Monitor a binary Iris classification task using a random forest. |
| `4_test_suites.py` | Compare flight delay data by month and run data quality and arrival delay tests. |

## Setup

Use Python 3.12. Dependency versions match the local coursework environment.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Run scripts from the repository root:

```bash
python 1_premiers_pas.py
python 2_regression_monitoring.py
python 3_classification_monitoring.py
python 4_test_suites.py
```

The first script downloads Adult from OpenML and requires internet access. The diabetes and Iris datasets are supplied by scikit-learn. Before running the fourth script, obtain the coursework flight delay archive separately and place it at `data/Delay_data.zip`. Its first archive member must be a CSV containing `Month` and `ArrDelay`; the script samples 10,000 rows and reads the first column as the index.

The first and fourth scripts export HTML reports in the repository root; the first also exports JSON. Scripts 2–4 save snapshots under `datascientest-workspace/`.

Datasets, generated reports, workspace snapshots, virtual environments, and caches are excluded from Git. They remain local and can be regenerated by running the scripts. Random sampling and simulated predictions mean results can vary between runs.
